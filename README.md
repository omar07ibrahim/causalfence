# CausalFence

CausalFence is a work-in-progress deterministic conformance lab for causal and
session guarantees in bounded multi-region key-value traces.

The original 2025 DTK LPR upload is preserved byte-for-byte under
[`legacy/dtk-lpr-2025/`](legacy/dtk-lpr-2025/) and is not part of this package.
